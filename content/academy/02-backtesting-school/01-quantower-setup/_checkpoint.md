## Why is delayed data a problem for forward testing but not for a bar-by-bar backtest?

- [ ] Delayed data has no volume.
- [ ] A backtest needs live data to replay history.
- [x] Forward testing happens in real time, so stale prices would mislead you, while a backtest replays bars that finished long ago.
